# Запуск SendBot на сервере — пошагово

Инструкция для человека без опыта администрирования. Всё, что нужно —
копировать команды и вставлять. Занимает 20–30 минут.

---

## Шаг 1. Купить сервер (~€40/мес)

1. Зайди на **console.hetzner.cloud**, зарегистрируйся, привяжи карту.
2. Нажми **New Project** → назови «SendBot» → зайди в него.
3. **Add Server** и выбери:
   - **Location:** Nuremberg или Helsinki (Германия/Финляндия)
   - **Image:** **Ubuntu 24.04**
   - **Type:** вкладка **Dedicated vCPU** → **CCX23** (4 ядра, 16 ГБ)
   - **Volume, Network, Firewall** — ничего не трогай
   - **Backups** — **включи галочку** (+20%, это спасёт при сбое)
   - **SSH keys** — пропусти, пароль придёт на почту
   - **Name:** sendbot
4. **Create & Buy now**. Через минуту сервер готов, запиши его **IP-адрес**
   (вида `95.216.xx.xx`) — он на странице сервера.

## Шаг 2. Купить домен (100–1500 ₽/год)

Любой регистратор: **reg.ru**, **namecheap.com**, **cloudflare.com**.
Купи что-то вроде `mysendbot.ru`.

Затем в панели регистратора найди **DNS-записи** и добавь запись:

| Тип | Имя | Значение |
|-----|-----|----------|
| A   | @   | IP-адрес твоего сервера |
| A   | www | IP-адрес твоего сервера |

Сохрани. Записи расходятся 5–30 минут.

## Шаг 3. Подключиться к серверу

Открой на Mac программу **Терминал** и введи (подставь свой IP):

```bash
ssh root@95.216.xx.xx
```

Спросит пароль — возьми его из письма Hetzner (при вводе пароль не виден,
это нормально). При первом входе попросит придумать новый пароль — придумай
и **сохрани его**.

## Шаг 4. Установить всё необходимое

Скопируй **целиком** этот блок и вставь в терминал:

```bash
apt update && apt install -y docker.io docker-compose-plugin ufw unzip
systemctl enable --now docker
ufw allow OpenSSH && ufw allow 80 && ufw allow 443 && ufw --force enable
mkdir -p /opt/sendbot && cd /opt/sendbot
echo "Готово. Docker установлен, файрвол включён."
```

## Шаг 5. Загрузить проект

На **своём компьютере** (не на сервере) открой **новое** окно терминала и
выполни, подставив свой IP и путь к архиву:

```bash
scp ~/Downloads/sendbot-src.zip root@95.216.xx.xx:/opt/sendbot/
```

Вернись в окно с сервером и распакуй:

```bash
cd /opt/sendbot && unzip -o sendbot-src.zip && mv "sendbot 9"/* . 2>/dev/null; ls
```

## Шаг 6. Настроить

```bash
cd /opt/sendbot
cp .env.example .env
nano .env
```

Открылся редактор. Заполни:

```
DOMAIN=mysendbot.ru                  ← твой домен
ADMIN_LOGIN=kirill                   ← твой логин для входа
ADMIN_PASSWORD=ПридумайСложныйПароль ← пароль владельца
SECRET_KEY=любые-случайные-30-символов
DB_PASSWORD=другой-сложный-пароль
```

`BOT_TOKEN` оставь пустым — ботов добавишь через админку.

Сохранить: **Ctrl+O**, **Enter**, выйти: **Ctrl+X**.

## Шаг 7. Запустить

```bash
cd /opt/sendbot
docker compose -f docker-compose.prod.yml up -d --build
```

Сборка занимает 2–4 минуты. Проверить, что всё поднялось:

```bash
docker compose -f docker-compose.prod.yml ps
```

Все строки должны быть в статусе **running**.

## Шаг 8. Открыть админку

Зайди в браузере на **https://mysendbot.ru** (свой домен).
Замок в адресной строке появится автоматически — сертификат выпускается сам.

Войди под логином и паролем из `.env`. Дальше:
- **Боты** → добавь бота с токеном от @BotFather → включи
- **Команда** → заведи сотрудников

---

## Что уже настроено автоматически

- **HTTPS** — сертификат выпускается и продлевается сам.
- **Автозапуск** — после перезагрузки сервера всё поднимется само.
- **Бэкапы базы** — каждую ночь в 03:00 в папку `/opt/sendbot/backups`,
  хранятся 14 последних копий. Плюс снапшоты всего сервера у Hetzner.

## Полезные команды

Выполнять на сервере в папке `/opt/sendbot`:

```bash
# посмотреть логи (Ctrl+C — выйти)
docker compose -f docker-compose.prod.yml logs -f app

# перезапустить
docker compose -f docker-compose.prod.yml restart

# обновить версию (после загрузки нового архива)
unzip -o sendbot-src.zip && mv "sendbot 9"/* . 2>/dev/null
docker compose -f docker-compose.prod.yml up -d --build

# список бэкапов
ls -lh backups/

# восстановить базу из бэкапа (ОСТОРОЖНО: заменит текущие данные)
gunzip -c backups/sendbot-20260101-0300.sql.gz | \
  docker compose -f docker-compose.prod.yml exec -T db psql -U sendbot sendbot
```

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| Сайт не открывается | Подожди 10–30 мин (DNS), проверь `docker compose -f docker-compose.prod.yml ps` |
| «Небезопасное соединение» | Сертификат ещё выпускается, подожди 2–3 минуты и обнови |
| Бот не отвечает | В админке: Боты → «Проверить» — покажет причину |
| Всё зависло | `docker compose -f docker-compose.prod.yml restart` |

## Роли и доступы

- **Владелец** — всё: боты и токены, ключ AI, управление командой.
- **Сотрудник** — воронки, рассылки, чаты, статистика. Не может добавлять
  ботов, менять токены и заводить пользователей. Можно ограничить доступ
  конкретными ботами (в разделе «Команда» при создании).

Каждому — свой логин и пароль. Отключить доступ: «Команда» → «Изменить» →
снять галочку активности, или «Удалить».
